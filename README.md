# NodeScope verified results

Generated by `.github/workflows/verify.yml`. Every node here passed a real proxy
handshake + HTTP test and an exit-IP trace from a GitHub Actions runner.

- `snapshot.json` – full snapshot consumed by the Cloudflare Worker
- `nodes.txt` / `nodes.b64` – plain / Base64 subscription of all verified nodes
- `clash.yaml` – ready-to-import mihomo / Clash Meta profile (nodes re-tested in Clash form)
- `stats.json` – run statistics and source health
- `history.json` – rolling per-node pass/fail history used for stability scores
