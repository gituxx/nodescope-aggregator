# NodeScope

**Каталог публичных прокси-узлов с прозрачными сведениями об источнике, местоположении и проверке соединения.** NodeScope объединяет открытые конфигурации, позволяет искать узлы и создавать подписки по протоколу, региону и стране. Это индекс данных, а не VPN-провайдер: проект не управляет перечисленными серверами и не подтверждает их надёжность.

**Языки:** [English](README.md) · [简体中文](README.zh-CN.md) · [فارسی](README.fa.md) · Русский · [မြန်မာ](README.my.md)

## Возможности

- Собирает публичные конфигурации VLESS, VMess, Shadowsocks, Trojan и других поддерживаемых протоколов.
- Ищет и фильтрует узлы по протоколу, региону, стране, заявленному статусу и задержке до входного узла.
- Создаёт Base64- или URI-подписки для всех узлов, 100 лучших, региона, страны или комбинации фильтров.
- Позволяет отдельно скопировать URI узла; общий API каталога не раскрывает исходные конфигурации и учётные данные.
- Показывает состояние источников и объясняет происхождение и ограничения данных о стране, статусе и задержке.
- Предоставляет многоязычный каталог открытых клиентов для компьютеров и мобильных устройств со ссылками на официальные релизы.

## Сбор из разных источников и устойчивость

Сборщик использует независимые пути, чтобы сбой одного репозитория не останавливал весь каталог:

- Агрегаторы и публичные репозитории GitHub: [MatinGhanbari/v2ray-configs](https://github.com/MatinGhanbari/v2ray-configs), [0xRadikal/Free-v2ray-Configs](https://github.com/0xRadikal/Free-v2ray-Configs), [Alirewa/V2ray-Configs](https://github.com/Alirewa/V2ray-Configs), [freenodess/freenodess](https://github.com/freenodess/freenodess), [morpheusadam/v2ray-config](https://github.com/morpheusadam/v2ray-config), [yuesuizhengrong/proxy-node-collector](https://github.com/yuesuizhengrong/proxy-node-collector), [Nexus-nodes](https://github.com/ninjastrikers/Nexus-nodes), [Au1rxx/free-vpn-subscriptions](https://github.com/Au1rxx/free-vpn-subscriptions) и [Free-Nodes](https://github.com/735754647/Free-Nodes).
- Публичный каталог [OpenProxyList](https://openproxylist.com/), зеркало открытого Telegram-канала [mfbpn/tg_mfbpn_sub](https://github.com/mfbpn/tg_mfbpn_sub) и публичный endpoint избранных подписок FreeNodeBiz.
- Страновые фиды для Японии, Южной Кореи, США, Гонконга, Сингапура, Тайваня, Австралии, Индии, Канады, Великобритании, Германии, Франции и Нидерландов.
- Разбор подписок Base64 и URI, прокси в формате Clash YAML и элементов RSS/Atom с последующей дедупликацией по идентификатору узла.

Планировщик Cloudflare Worker обновляет фиды каждые четыре часа и проверяет до 20 уникальных TCP-точек каждые две минуты. При сбое GitHub Raw выполняется повторная попытка через jsDelivr; лимиты сбора распределяются между владельцами проектов. Данные и результаты проверок хранятся в Cloudflare KV. Если запланированный снимок недоступен, Pages Function может выполнить сбор по запросу. При ошибке обновления или резком падении количества узлов сохраняется последний корректный снимок, записывается ошибка источника и ограничиваются повторные попытки. Устаревший снимок может выдаваться до семи дней; результаты отдельных проверок истекают через 12 часов.

Новые источники принимаются через GitHub Issues и проверяются до включения. URL от пользователей автоматически не загружаются.

## Значение статусов и стран

- `reachable`: Cloudflare установил TCP-соединение с входным адресом и портом узла. Это не проверяет рукопожатие прокси, аутентификацию, маршрутизацию или выход.
- `available`: источник опубликовал недавний результат бенчмарка. Это не независимая проверка протокола NodeScope.
- `upstream`: исходный проект выбрал или отметил узел; NodeScope не подтверждал его отдельно.
- `failed`: проверка входящего TCP-соединения не удалась. Известные ограничения Cloudflare и протоколы, которые нельзя проверить через TCP, помечаются как неподдерживаемые.
- `unknown` / `unsupported`: свежего результата нет или способ проверки неприменим.
- Страна может быть получена из отчёта источника об IP выхода, странового фида, имени узла или геолокации входного IP. **Страна входного IP не является страной выхода прокси.** Источник метки виден в интерфейсе.
- Задержка измеряет только TCP-соединение из Cloudflare до входной точки, а не сквозную задержку прокси и не качество сервиса.

## API подписок

```text
GET /api/subscription?format=base64&profile=all
GET /api/subscription?format=plain&profile=best100
GET /api/subscription?format=base64&profile=all&protocol=VLESS&region=apac&country=JP&country=KR
```

`format`: `base64` или `plain`. `profile`: `all`, `best100`, `apac`, `west` или код страны из текущего снимка. `region`: `apac`, `europe`, `americas` или `west`. Параметры `protocol` и `country` можно повторять; выбранные ограничения пересекаются. Для старых ссылок код страны можно передать как `profile=JP`.

Другие endpoints: `GET /api/nodes` возвращает метаданные и состояние источников без исходных URI; `GET /api/node?index=N&version=SNAPSHOT_TIME` возвращает URI одного узла для копирования; `GET /api/stats` возвращает сводную статистику.

## Языки, загрузки и SEO

Стабильные адреса интерфейса: `/` (китайский), `/en/`, `/fa/`, `/ru/` и `/my/`; для каждого языка есть отдельная страница `/downloads/`. Сборка формирует локализованные заголовки и описания, canonical URL, взаимные ссылки `hreflang`, структурированные данные и многоязычный sitemap. Персидская версия использует направление справа налево. Автоматического перенаправления по IP нет — язык выбирает посетитель.

Страница загрузок ведёт к официальным релизам v2rayN, Clash Verge Rev, FlClash, Hiddify, v2rayNG, NekoBox и Karing. Перед установкой проверяйте релиз и пакет в официальном проекте.

## Разработка и развёртывание

Нужны актуальная версия Node.js LTS и npm.

```sh
npm install
npm run dev
npm run build
```

`npm run build` создаёт в `dist/` сайт Cloudflare Pages, статические языковые маршруты и `sitemap.xml`. Для локального запуска Pages Functions используйте `npm run dev:pages`; `npm test` запускает тесты Node.

Сайт размещается в Cloudflare Pages через Direct Upload, сборщик работает как запланированный Cloudflare Worker. Настройте KV namespace `NODESCOPE_DATA` для Pages и Worker и добавьте `node.oinnn.top` в Custom domains проекта Pages.

```sh
npx wrangler login
npm run build
npm run deploy:cloudflare
npm run deploy:collector
```

Репозиторий публичный. Не добавляйте ключи Cloudflare, персональные токены GitHub, приватные URL фидов или учётные данные подписок. Для деплоя используйте авторизованную сессию Wrangler или секреты с минимальными правами.

## Безопасность и лицензия

Публичными узлами могут управлять неизвестные третьи стороны; они могут измениться или наблюдать за трафиком. Не используйте их для аккаунтов, платежей, частной переписки и других чувствительных данных. Соблюдайте местные законы и правила сети.
